# Straatwijsheid website

The site for <https://straatwijsheid.nl>: Astro with Starlight, deployed to GitHub Pages.

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # static site in dist/
npm run tokens    # regenerate branding/tokens.css and fonts.css, check contrast
```

- `branding/` is the design system: `tokens.json` is the source, `preview.html` shows it (regenerated by `npm run tokens`).
- `src/styles/theme.css` maps the tokens onto Starlight.
- `src/content/docs/` holds the pages. English is the root locale; a Dutch translation can be added as a `nl` locale later.
- The map is embedded from <https://maps.straatwijsheid.nl/>.
- Planned: documentation synced from the code and knowledge repositories, and the contribution form (a Cloudflare Worker that opens issues in a private repository).

# Fonts

Overpass (Red Hat / Delve Withrington), a Highway Gothic-inspired family, from the official release
<https://github.com/RedHatOfficial/Overpass/releases/tag/3.0.1> (`overpass-webfonts.zip`), see <https://overpassfont.org/>.
Licence: SIL Open Font Licence 1.1 (`OFL.txt`). Self-hosted: the site makes no requests to a font CDN.

Weights used: regular 400, semibold 600, bold 700, extrabold 800 (WOFF2 only).
